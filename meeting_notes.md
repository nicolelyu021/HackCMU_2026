# App Concept: AI Travel Journal Chatbot

- Core idea: chatbot-style app that acts as an interactive travel diary
  - Users can talk to their journal (“this is my journal”) via AI chat
  - Described as “like Compact, but in a useful interface, like a diary book”
- Key features discussed:
  - Chat UI with notification function
  - Journal entries with AI summarization
  - Trip cards (e.g., Miami 2026, New York 2025)
  - Map with location pins and timeline
  - Vlog/video integration (AI-generated visuals via GenJutsu, Higgs field solve)

# App Structure and UI

- Shell, Landing Page, Navigation
- Chat UI and Journal view
- Trip Cards and Map Diagrams
- AI Flow and Prompt layer
- Backend: endpoint retrieval from trip and journal data

# Tech and Demo Plan

- Frontend, backend, cloud, and AI components scoped
- Demo flow: trip entry, location map pins, timeline
- Iteration order: landing page, navigation, chat UI, journal, map
- VR/location UI mentioned as a stretch direction
