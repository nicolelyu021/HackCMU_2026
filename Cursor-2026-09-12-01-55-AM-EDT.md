## What this project is

One loop, three screens:

1. **Plan** — type “Kyoto, 2 days, temples + food.” Stickers drop onto the map one by one.
2. **Live it** — drop a photo. The phone reads the photo’s hidden GPS/time (**EXIF** = the “where/when stamp” cameras write into a JPEG). If it is close enough to a sticker (300 m and ±2 hours), it lands there. No GPS → it waits in a tray.
3. **Relive it** — tap Make vlog. The app writes a short script from **your notes**, draws a map flyover, Ken-Burns your photos, and (optionally) speaks the script.

That last part is **Remotion**: a tool that turns React screens into a video timeline. It is like iMovie with code. It is **not** Gemini/Veo generating footage.

The product name is Pinlog. Your folder is `apps/web/`. You are owner **A** (Client Lead): you drive the demo laptop. Yara has been building features; Jane already said the HTML prototype’s map is fine but the **UI looks cheap** next to 小红书 / 赛博手账.
